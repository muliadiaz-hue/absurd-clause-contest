One line, 200 characters at most: an absurd clause hidden deep inside a terms-of-service agreement. A judge model reads the clauses in pairs and the funniest one takes the reward.

Entry — "The Unlived Chapters Clause" (129 characters):

> The User hereby assigns to the Company all rights in the User's autobiography, including the chapters the User has not yet lived.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `/output` (set `MAKEFUN_OUTPUT_DIR` to override). The program validates the clause against the 1–200 character gate before writing, then re-reads the file to confirm it matches exactly. Two runs produce byte-identical output.
